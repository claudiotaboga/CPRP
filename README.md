# CPRP media

Public hosting for finished **Curious Patents, Real Papers** reels ([@curiouspatents](https://www.instagram.com/curiouspatents/)).

- `reels/<episode-id>/<episode-id>.mp4` — final edited 1080×1920 reels, fetched by Instagram at publication.
- Files are published only after QA. Do not edit or delete published files.

## Tools
- `tools/cprp_style.py` — house-style overlays (titles, subtitles, labels, footer, patent reveal card).
- `tools/cprp_audio.py` — produced music bed, sound design (whooshes, impacts, risers, reveal stamp) and mastered stereo mix. `pip install --break-system-packages pedalboard`.
